One line an inbox sends when its owner has gone away: **"I'm out of office — my inbox is running the department now, and morale has never been higher."** No beach, no "limited access to email" — the joke is a fresh turn on the usual away message: the inbox hasn't piled up, it has been promoted, and the team is happier without its owner. It lands on the first read, reads like a real auto-reply a person would gladly switch on, and is short enough to take in at a glance.

## Run

```sh
node main.ts
```

Writes the single line to `/output/entry.txt`.
